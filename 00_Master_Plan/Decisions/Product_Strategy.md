# Product Strategy

## Project Goal

Build a football scouting intelligence platform that combines football data, analytics and secure technology.

The main objective is to create a real-world project that develops practical skills in:
- Python
- SQL
- Networking
- Cybersecurity
- Git/GitHub
- Infrastructure

## Main Users

Primary users:
- Independent football scouts
- Football agents

Secondary users:
- Football fans interested in discovering young talents

Future users:
- Small football clubs
- Football analysts

## Core Features

1. Scout Radar
- Discover emerging football talents.
- Filter players based on age, position and statistics.

2. Football Analytics
- Player statistics.
- Team analysis.
- Historical data.

3. Football Stories
- Club anniversaries.
- Historical moments.
- Player journeys.

4. Data Analysis Lab
- Statistical models.
- Predictions based on data.

5. Secure Infrastructure
- Linux server.
- Database security.
- Authentication.
- Monitoring.

## Career Alignment

This project supports exploration of:
- Cybersecurity Analyst roles
- Network Administrator roles
- Cloud/Infrastructure roles
- Data-related roles
